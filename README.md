# Durvasa Muni Heritage & Wisdom Website

A lightweight, responsive, and spiritually inspired single-page website template dedicated to **Maharishi Durvasa**—the revered ancient sage of absolute truth, intense austerity, and divine transformation.

---

## 🌟 Features

* **Traditional & Modern Aesthetic:** Uses warm earthy tones (deep saffron, maroon, and parchment backgrounds) paired with elegant Google Fonts (`Cinzel` for traditional headings and `Poppins` for clean body text).
* **Fully Responsive Design:** Flexbox and CSS Grid layout automatically adapt to mobile devices, tablets, and desktops.
* **Structured Sections:** 
  * **Hero Header:** Captivating introduction with navigation anchors.
  * **About Section:** Background on Durvasa Muni as an avatar of Lord Shiva.
  * **Divine Legends:** Key mythological stories including Shakuntala's curse and the tale of King Ambarisha.
  * **Core Teachings:** Highlighted quotes and principles regarding ego-annihilation, humility, and *Tapasya*.
  * **Legacy:** Summary of his spiritual role in Vedic lore.
